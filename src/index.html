主题
主题以 JSON 保存在数据目录的 themes 文件夹中，可直接编辑，也会随数据备份一起导入导出。
窗口材质
Windows 11 使用 DWM 系统背景；旧版本自动使用兼容的 Mica、Acrylic 或 Blur。
数据存储位置
笔记与待办以 data.json 保存在此目录，切换时会自动迁移已有数据。
—
图片存储位置
Ctrl+V 粘贴的截图保存到此目录，默认位于数据目录下的 images；放在数据目录内才会随备份导出。

启动时窗口置顶

数据备份
