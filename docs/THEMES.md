# 自定义主题

小便签的主题保存在**数据目录**下的 `themes` 文件夹中，每套主题对应一个 JSON 文件。首次启动会生成 `sakura.json`（粉樱）、`midnight.json`（暗夜）、`mint.json`（薄荷）和 `paper.json`（素纸）。

默认数据目录为 `%APPDATA%\com.notepaper.sticky`。如果修改过数据存储位置，请在设置页查看实际路径。只有文件缺失时才会重新生成内置主题，应用不会主动覆盖已有文件。

## 快速开始

1. 在设置页点击“打开目录”，进入 `themes` 文件夹。
2. 复制 `sakura.json`，重命名为例如 `ocean.json`。
3. 修改文件中的 `id`、`name` 和 `variables`，并确保 `id` 为 `ocean`。
4. 保存后重新打开设置页，新主题就会出现在主题列表中。

也可以在设置页使用“导出当前主题”生成 JSON 模板，修改后再通过“导入主题”导入。导入与已有主题相同的 `id` 会覆盖对应文件。

## JSON 格式

```json
{
  "id": "ocean",
  "name": "海洋",
  "colorScheme": "dark",
  "variables": {
    "--app-bg": "linear-gradient(165deg, #102a43 0%, #243b53 100%)",
    "--plum": "#9fd8ff",
    "--plum-2": "#6cb6e8",
    "--ink": "#f0f7ff",
    "--ink-soft": "#b8c9d9",
    "--line": "rgba(255, 255, 255, 0.14)",
    "--card": "rgba(255, 255, 255, 0.07)",
    "--surface": "rgba(255, 255, 255, 0.08)",
    "--surface-strong": "rgba(255, 255, 255, 0.14)",
    "--accent-bar": "linear-gradient(90deg, #2680c2, #6cb6e8)",
    "--on-ink": "#102a43",
    "--code-bg": "rgba(0, 0, 0, 0.25)",
    "--code-text": "#e6f4ff"
  }
}
```

| 字段 | 规则 |
| --- | --- |
| `id` | 必填，1–40 位小写字母、数字、`-` 或 `_`，以字母或数字开头；必须与文件名（不含 `.json`）一致 |
| `name` | 必填，设置页显示的名称，最长 40 个字符 |
| `colorScheme` | `light` 或 `dark`，省略时按 `light` 处理；影响系统原生控件的明暗配色 |
| `variables` | 至少包含一个下表中的 CSS 变量；未指定的变量使用粉樱默认值 |

JSON 必须使用双引号，不能包含注释或末尾多余逗号。建议先导出内置主题，再在副本上修改。

## 可编辑变量

### 界面与文字

| 变量 | 用途 | 示例 |
| --- | --- | --- |
| `--plum` | 主色，用于标题、按钮、链接等 | `#74406f` |
| `--plum-2` | 辅助主色，用于悬停和渐变 | `#9b5f92` |
| `--ink` | 主要文字颜色 | `#2f2333` |
| `--ink-soft` | 次要文字、提示信息 | `#75627a` |
| `--on-ink` | 主色背景上的文字或图标 | `#ffffff` |
| `--danger` | 删除等危险操作 | `#9c3563` |
| `--line` | 分隔线与边框 | `rgba(116, 64, 111, 0.16)` |
| `--stroke` | 高亮描边 | `rgba(255, 255, 255, 0.7)` |

### 背景、卡片与控件

| 变量 | 用途 |
| --- | --- |
| `--app-bg` | 整个窗口背景，支持颜色或 CSS 渐变 |
| `--accent-bar` | 笔记标题下方强调条，支持颜色或 CSS 渐变 |
| `--card` | 普通卡片背景 |
| `--surface` | 输入框、列表项等控件背景 |
| `--surface-strong` | 悬停或强调状态的控件背景 |
| `--popover-bg` | 笔记列表、设置页等浮层背景 |
| `--shadow` | 窗口或浮层阴影，使用 CSS `box-shadow` 值 |
| `--tint` | 轻量主色衬底 |
| `--tint-strong` | 较强的主色衬底 |
| `--switch-off` | 开关关闭状态的轨道颜色 |
| `--scroll-thumb` | 滚动条颜色 |
| `--scroll-thumb-hover` | 滚动条悬停颜色 |

### 字体

| 变量 | 用途 |
| --- | --- |
| `--ui-font` | 应用界面字体 |
| `--preview-font` | Markdown 预览字体 |
| `--mono-font` | 编辑器与代码字体 |

字体值按 CSS `font-family` 规则填写，可以列出多个本地字体作为回退，例如 `Georgia, Noto Serif SC, SimSun, serif`。主题不会下载字体，最终效果取决于系统已安装的字体。

### 代码块与语法高亮

| 变量 | 用途 |
| --- | --- |
| `--code-bg` | 代码块背景 |
| `--code-head` | 代码块顶部语言栏背景 |
| `--code-text` | 普通代码文字 |
| `--token-keyword` | 关键字 |
| `--token-string` | 字符串 |
| `--token-number` | 数字 |
| `--token-comment` | 注释 |
| `--token-fn` | 函数名 |
| `--token-tag` | HTML/XML 标签名 |
| `--token-attr` | HTML/XML 属性名 |
| `--token-bool` | 布尔值与空值 |

## 校验与限制

- 单个主题文件最大 128KB。
- 变量值不能为空，最长 1000 字节，并且不能包含控制字符、`{ } ; < >`。
- 不允许 `url(`、`expression(`、`@import` 或 `javascript:`，因此主题不能加载远程图片、字体或执行脚本。
- 只能修改上述白名单变量；不支持任意 CSS 选择器、布局尺寸、窗口圆角、动画或自定义图标。
- JSON 格式或校验失败时，应用会回退到内置 CSS 主题，并在设置页显示错误；修正文件后重新打开设置页即可重试。

## 导入、导出与备份

- **导出当前主题**：将当前选中的主题另存为单个 JSON 文件。
- **导入主题**：选择一个合法 JSON 文件，写入当前数据目录的 `themes`，随后自动切换到该主题。
- **数据备份**：设置页的 zip 备份会包含整个 `themes` 目录，与 `data.json`、数据目录内图片一起迁移。
- **恢复备份**：同名主题文件会被备份中的版本覆盖；当前主题 ID 仍保存在应用设置中，如果恢复后找不到该 ID，则回退到粉樱。
- **切换数据目录**：旧数据目录中的主题会复制到新目录，但不会覆盖新目录已有文件。
